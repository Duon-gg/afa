# Design tokens

- Body: Roboto, Helvetica Neue, Helvetica, Arial, sans-serif.
- Headings: Roboto Condensed and Roboto Slab where assigned by the source.
- Core text: `rgb(51, 51, 51)`; muted text includes `rgb(77, 77, 77)` and `rgb(102, 102, 102)`.
- UN blue: `rgb(10, 90, 130)`; light blue section background: `rgb(234, 243, 251)`.
- White: `rgb(255, 255, 255)`; light gray: `rgb(242, 242, 242)`; dark footer: `rgb(18, 19, 20)`.
- Existing Bootstrap 3 grid and source stylesheets remain the authority for spacing and responsive behavior.
