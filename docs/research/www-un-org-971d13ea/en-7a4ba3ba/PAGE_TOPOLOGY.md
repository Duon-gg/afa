# English home topology

The source uses a Drupal 7 page shell with Bootstrap 3. The visible order is: UN brand bar, logo/search/main navigation, feature hero, news grid, In Focus, Sustainable Development Goals, More from the United Nations, What we do, UN structure, Learn more, facts, watch/listen, pictures, directory footer, and legal footer.

The header menus are click-driven on narrow screens and hover/click-driven on desktop. Media areas contain external iframes and time-driven carousels. The page itself uses normal document scrolling. The clone preserves the source HTML, styles, scripts, breakpoints, and asset URLs; its only page-level addition is the fixed EN/VI switch.
